{#- Weave people: avatars and names. Contracts and examples: /-/design/people. -#} {%- import "macros.html" as m -%} {#- The avatar of the account `name`, at an icon's height. Decorative: the name next to it carries the meaning. -#} {%- macro avatar(ctx, name) -%} {%- match ctx.avatar(name) -%} {%- when crate::ui::AvatarView::Uploaded with (url) -%} {%- when crate::ui::AvatarView::Generated with (tone, path) -%} {%- endmatch -%} {%- endmacro -%} {#- An account's name: its avatar and name, one link to the account unless `link` is false, and the Bot badge after a bot's name. -#} {%- macro account(ctx, name, link = true) -%} {%- if link -%} {% call avatar(ctx, name) %}{% endcall %}{{ name }} {%- else -%} {% call avatar(ctx, name) %}{% endcall %}{{ name }} {%- endif -%} {%- if ctx.is_bot(name) %} Bot{% endif -%} {%- endmacro -%} {#- An account that no longer exists: a neutral placeholder, never the pattern of its old name. -#} {%- macro deleted(ctx, text = "a deleted user") -%} {% call m::icon(ctx, "user") %}{% endcall %}{{ text }} {%- endmacro -%} {#- Who did something (a `crate::ui::Who`): an account's name, the deleted placeholder, Slath itself, or someone unknown. `start` writes the words that begin a sentence capitalized; `link` false where the name sits inside another control (a summary, a link). -#} {%- macro who(ctx, w, start = true, link = true) -%} {%- match w -%} {%- when crate::ui::Who::Account with (n) -%}{% call account(ctx, n, link) %}{% endcall %} {%- when crate::ui::Who::Deleted -%}{% if start %}{% call deleted(ctx, "A deleted user") %}{% endcall %}{% else %}{% call deleted(ctx) %}{% endcall %}{% endif %} {%- when crate::ui::Who::Slath -%}{% call m::icon(ctx, "bot") %}{% endcall %}Slath {%- when crate::ui::Who::Unknown -%}{% if start %}Someone{% else %}someone{% endif %} {%- endmatch -%} {%- endmacro -%} {#- An author or committer written into a commit. `account` is the account whose confirmed address the commit uses, or empty: matched, it's that account's name, with the name as written in its tooltip; unmatched, a neutral person icon and the name as written. -#} {%- macro git_identity(ctx, name, account) -%} {%- if account.is_empty() -%} {% call m::icon(ctx, "user") %}{% endcall %}{{ name }} {%- else -%} {% call avatar(ctx, account) %}{% endcall %}{{ account }} {%- if ctx.is_bot(account) %} Bot{% endif -%} {%- endif -%} {%- endmacro -%} {#- Several accounts in a small space: up to three avatars, then "+N". Every name, after `label` ("Reviewers") when given, is the group's tooltip and the same text for screen readers, so it's read once. -#} {%- macro avatar_group(ctx, names, label = "") -%} {%- let group_names %}{% if !label.is_empty() %}{{ label }}: {% endif %}{{ names|join(", ") }}{% endlet -%} {%- for n in names.iter().take(3) %}{% call avatar(ctx, n) %}{% endcall %}{% endfor -%} {%- if names.len() > 3 %}+{{ names.len() - 3 }}{% endif -%} {{ group_names }} {%- endmacro -%}
