{#- Weave people: avatars and names. Contracts and examples: /-/design/people. -#} {%- import "macros.html" as m -%} {#- The avatar of the account `name`, at an icon's height. Decorative: the name next to it carries the meaning. -#} {%- macro avatar(ctx, name) -%} {%- match ctx.avatar(name) -%} {%- when crate::ui::AvatarView::Uploaded with (url) -%} {%- when crate::ui::AvatarView::Generated with (tone, path) -%} {%- endmatch -%} {%- endmacro -%} {#- An account's name: its avatar and name, one link to the account unless `link` is false, and the Bot badge after a bot's name. -#} {%- macro account(ctx, name, link = true) -%} {%- if link -%} {% call avatar(ctx, name) %}{% endcall %}{{ name }} {%- else -%} {% call avatar(ctx, name) %}{% endcall %}{{ name }} {%- endif -%} {%- if ctx.is_bot(name) %} Bot{% endif -%} {%- endmacro -%} {#- An account that no longer exists: a neutral placeholder, never the pattern of its old name. -#} {%- macro deleted(ctx, text = "a deleted user") -%} {% call m::icon(ctx, "user") %}{% endcall %}{{ text }} {%- endmacro -%} {#- An author or committer written into a commit: a claim, not an account, so a neutral person icon and the name as written. -#} {%- macro git_identity(ctx, name) -%} {% call m::icon(ctx, "user") %}{% endcall %}{{ name }} {%- endmacro -%} {#- Several accounts in a small space: up to three avatars, then "+N"; every name is text for screen readers. -#} {%- macro avatar_group(ctx, names) -%} {%- for n in names.iter().take(3) %}{% call avatar(ctx, n) %}{% endcall %}{% endfor -%} {%- if names.len() > 3 %}+{{ names.len() - 3 }}{% endif -%} {{ names|join(", ") }} {%- endmacro -%}
