Push protection

{%- call c::popover(ctx, "About push protection") %}

Unless it's off, Slath checks each push for secrets, such as access tokens and private keys, before it accepts the push.

A finding that isn't a secret can be allowed from the link the push prints; who may allow it is set below.

Agent context

{%- call c::popover(ctx, "About agent context") %}

Agents can upload an account of how they made a change: a summary and, if kept, the transcript. It shows next to the change on its merge request.

Records are encrypted, never part of the repository's Git data, and never copied to forks.
