Basic controls

A link goes somewhere; a button does something. Tooltips name icon-only controls and show a value's full form; they work with a mouse, the keyboard, and touch, and never hold something only they say.

{%- call cat::entry("links", "Links and buttons", "New") %}
Purpose
A link goes to another page or a place on this one; a button changes data, opens a menu, or copies. A link's text names where it goes, never "here" or "more". A link to another site ends with the external-link icon.
Markup
<a href> for links, c::external(ctx, href, text) for other sites; <button> for actions.
Variants
Link; link to another site; button (see the buttons in the overview).
Accessibility
A link never submits and a button never only navigates, so each behaves as its role says. Links to other sites say so to screen readers.
Not for
Actions that look like links (they're quiet buttons).

{%- endcall %} {%- endcall %} {%- call cat::entry("tooltip", "Tooltip", "New") %}
Purpose
Names an icon-only control, or shows a value's full form: the exact time of a relative one, a full hash, a cut text. It appears on hover, on keyboard focus, and on a tap; Escape, a tap elsewhere, or scrolling closes it.
Markup
data-tip="text" on the element; c::icon_button(ctx, icon, name) for icon-only buttons. The browser's title isn't used: touch screens and keyboards never show it.
Variants
Below the element, or above it where there's no room; always inside the screen.
Accessibility
Never the only place of something needed to act: an icon-only button has its name for screen readers too. Where the text adds to the element's name, screen readers get it as the element's description.
Not for
Help or anything longer than a phrase (a popover or a hint).

{%- endcall %} {%- endcall %} {%- call cat::entry("time", "Time", "New") %}
Purpose
A moment: relative within seven days ("3 hours ago", "in 2 days", "yesterday"), a date otherwise ("14 Nov 2026"), and the exact date and time with its zone in the tooltip. Where the exact moment is the point (the audit log, deliveries, sessions, tokens, administration) it's shown in full.
Markup
c::time(t), or c::time(t, true) for the full form; t is the page's time value.
Variants
Past; future; older than a week; full.
Accessibility
A time element with its exact value; the short form is the text read aloud.
Not for
Calendar dates without a time (a milestone's due date).

{%- endcall %} {%- endcall %} {%- call cat::entry("hash", "Hash and path", "New") %}
Purpose
A commit hash shows its first 12 characters, linked, with the full hash in its tooltip. A file path wraps after a slash, never inside a name.
Markup
c::hash(oid, href); c::path(path).
Variants
None.
Accessibility
Both stay left to right in every language; the full hash is the link's description.
Not for
Change IDs (shown in full, 8 characters).

{%- endcall %} {%- endcall %} {%- call cat::entry("cut", "Cut text", "New") %}
Purpose
Text cut short where its space is fixed (a table cell, a list row, a menu item): it ends with "…", and its full form is in the tooltip and on the page it links to. Titles, names, and branch names wrap instead.
Markup
c::cut(text) inside the fixed space.
Variants
None.
Accessibility
The whole text stays in the page for screen readers; the tooltip shows it on hover, focus, and tap.
Not for
Anything a person must read in full to act.

{%- endcall %} {%- endcall %} {%- call cat::entry("popover", "Popover", "New") %}
Purpose
More about something, on request: help for a setting, what a state means. Opened by click, tap, or Enter; closed by Escape or a click outside; focus moves into it and back.
Markup
c::popover(ctx, label, icon) around the text.
Variants
None.
Accessibility
The button is named by label; the panel is a group with the same name and takes focus.
Not for
Anything needed to finish a task (put it in the hint or the page); actions (a menu).

{%- endcall %} {%- endcall %} {%- call cat::entry("password", "Password field", "New") %}
Purpose
A password: an eye button inside the field, at its end, shows and hides the text; pasting is never blocked, and the field tells password managers what it's for.
Markup
A field with input type=password and its autocomplete value (current-password, new-password); the script adds the button.
Variants
Hidden (an eye); shown (a crossed-out eye, the button pressed).
Accessibility
An icon-only toggle named "Show password" (also its tooltip) that reports whether it's pressed and controls the field; sending the form hides the text again.
Not for
Tokens and secrets shown once (a value to copy).

{%- endcall %} {%- endcall %} {%- call cat::entry("count", "Length count", "New") %}
Purpose
A field with a length limit says it in its hint; once the text comes within a fifth of the limit, the characters left appear under the field.
Markup
The control's maxlength; the script adds the count.
Variants
Far from the limit (nothing shown); near it.
Accessibility
The count describes the field and is announced politely as it changes.
Not for
Fields without a limit.

{%- endcall %} {%- endcall %} {%- call cat::entry("names", "Field for several names", "New") %}
Purpose
Several people, teams, or labels in one field (reviewers, assignees, labels): suggestions while typing, and each chosen name as a removable chip with its avatar.
Markup
A field whose input has data-names (data-names="labels" for labels, without avatars) and, for people, data-suggest-users="owner/repo", with data-suggest-teams where teams of the organization fit too (reviewers). Without scripts it's plain text, names separated by commas.
Variants
Empty; with chips; suggesting.
Accessibility
The chips are a list named "Chosen"; each remove button is named ("Remove bob"); Backspace in the empty box removes the last chip.
Not for
One name (a field for one name).
{%- call cat::example("Two reviewers chosen; type another and a comma.") %}
{%- call f::field("demo-reviewers", "Reviewers", "Usernames, or organization/team, separated by commas.") %}{% endcall %}
{%- endcall %} {%- endcall %} {%- call cat::entry("name-field", "Field for one name", "New") %}
Purpose
One person, or one person or team, in a text field (who decides on an approval): suggestions while typing, and choosing one puts its name in the field.
Markup
A field whose input has data-suggest-users="owner/repo" and data-suggest-single, with data-suggest-teams where a team of the organization fits too (suggested as org/team, after the people). Without scripts it's a plain text field.
Variants
Empty; suggesting; with an error.
Accessibility
A combobox with a listbox named "People" or "People and teams"; Up and Down choose, Enter or Tab accept, Escape closes.
Not for
Several names (a field for several names).

{%- endcall %} {%- endcall %} {%- call cat::entry("sort", "Sorting", "New") %}
Purpose
The order of a list is one of its views: a view menu ("Sort: Newest") next to the others, not a field among the filters.
Markup
m::view_menu(ctx, "Sort", current, region) with one m::view_item per order.
Variants
As the view menu.
Accessibility
As the view menu: the button names the order shown.
Not for
Filters.

{%- endcall %} {%- endcall %} {%- call cat::entry("switches", "On and off", "New") %}
Purpose
There are no toggle switches. A setting that's on or off is a checkbox saved with its form's button; an action that takes effect at once is a button that names it ("Watch", "Unwatch", "Stop bot"). Dates are entered with the browser's date field.
Markup
An option without a question (f::option("checkbox", …)); a button; input type=date in a field.
Variants
None.
Accessibility
Native controls, labelled.
Not for
Mutually exclusive alternatives (the choice component).

{%- endcall %} {%- endcall %} {%- call cat::entry("dialog", "Dialog", "New") %}
Purpose
Something to read or choose over the page without leaving it, such as the list of keyboard shortcuts. A button on the page opens it; it holds no step that only it offers.
Markup
c::dialog(ctx, id, title) with the content as its body, and a button[data-dialog] whose aria-controls names it. Dialogs need scripts: a button that only opens one is hidden until they run.
Variants
None.
Accessibility
A modal dialog named by its heading: focus moves into it and stays there, Escape and the close button close it, and focus goes back to the button that opened it.
Not for
Forms that are a page's task (a page), confirmations (the danger section), or help for one setting (a popover).

Next change of the stack
k
Previous change of the stack
{%- endcall %} {%- endcall %} {%- endcall %} {%- call cat::entry("shortcuts", "Keyboard shortcuts", "New") %}
Purpose
Faster ways to do what buttons and links already do. Every shortcut follows a control on the page and never does more than it; the list of shortcuts names them all, by where they work.
Markup
aria-keyshortcuts on the control, and its key in its tooltip ("Next change (n)"); a single-key shortcut that follows a link marks it with data-key. Scripts check singleKey(e) (web/src/keys.ts) before acting on a key without Ctrl or ⌘. Each shortcut is listed in shortcuts.html, opened by ? and the footer's "Keyboard shortcuts" button.
Variants
Single keys (j, n, ?): only while focus is in their component, or, for ?, anywhere outside fields. With Ctrl or ⌘ (Ctrl+Enter): where they're listed.
Accessibility
Single keys never act while focus is in a field, and each person can turn them off (Settings → Appearance, or the list's own button), as WCAG 2.1.4 asks; shortcuts with Ctrl or ⌘ stay. Each one has a button or link that does the same.
Not for
Actions without a control on the page; keys the browser or screen readers use (arrows outside composite widgets, Alt+letters).
{%- call cat::example("The footer's button opens the list of this page.") %} {%- endcall %} {%- endcall %} {%- call cat::entry("palette", "Command palette", "New") %}
Purpose
Reaching any of the page's actions by name from the keyboard: the links and buttons of the global bar, the side menu, the tabs, the page heading's actions, and the footer, and every control with a shortcut, each with where it is and its keys. Taking one follows that link or presses that button.
Markup
Drawn by the frame (palette.html, a dialog) and filled from the page when it opens; nothing to add to a page. An action shows up when it's in one of those places or has aria-keyshortcuts; menu items, links within the page that aren't shortcuts, and disabled controls don't.
Variants
None.
Accessibility
Opened by Ctrl+K (⌘K) or the global bar's button. A combobox field with a listbox: typing filters, ↑ and ↓ choose, Enter, a click, or a tap takes one, Escape closes; the number of matching actions is announced. In the editor, Ctrl+K stays the link shortcut.
Not for
Search (the search page), or actions the page doesn't offer.
