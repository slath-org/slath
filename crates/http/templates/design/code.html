Code

Code is one of Slath's most important content types: diffs that read correctly, long-form text people write, and the editor they write it in.

{%- call cat::entry("code-toolbar", "Code toolbar", "New") %}
Purpose
Above the files of the code pages: the branch, tag, or commit shown with its switcher and its commit on the start side, how a fork's branch compares with its parent, and Download and Clone at the end.
Markup
repo/ref_line.html (the branch switcher is a menu with ref-panel, whose branch list scrolls), repo/fork_compare.html, and repo/clone.html (alternatives one at a time, each a value to copy).
Variants
Branch, tag, commit (no commit after the switcher); a fork's branch ahead or behind, with Sync fork; the repository home's Clone alone.
Accessibility
The switcher's button says what's shown and what it does ("Branch main: switch branch"); the current branch is marked as current.
Not for
Views of a list (a view menu).

{%- endcall %} {%- endcall %} {%- call cat::entry("code-view", "Code view and blame", "New") %}
Purpose
A file's lines with their numbers, highlighted, in a box that scrolls sideways while the numbers stay; a line's number links to it and marks it. Above it the file's links (Raw, Blame, History, Permalink) and its language and length. Blame adds each run of lines' commit: its hash, its summary cut to the column, its author, and when.
Markup
p.file-actions, then div.code-wrap > table.code-view.code-table; blame adds blame-table, a td.blame-commit spanning the run, and tr.blame-start on its first line.
Variants
File; blame; a range diff (pre.range-diff, plain text in the box); too large or binary (a notice with the raw file instead).
Accessibility
A region named by what it shows; line numbers are row headers; the blame's column headers are there for screen readers.
Not for
Changes (the diff); commands to copy (a code block).

Purpose
A folder's README under its files: the file's name as a file heading, outside the box so it isn't read as the file's first line, then the rendered Markdown (or the plain text) in a box.
Markup
section.section.readme > h2.readme-name, then div.readme-body around rendered Markdown.
Variants
Markdown; plain text.
Accessibility
A section named by the file's name; the Markdown's own headings start below it.
Not for
Other files (the code view).

Purpose
The body of a commit message under its subject (the page title), as written: line breaks kept, in the interface font, not interpreted as Markdown.
Markup
pre.commit-body.
Variants
None; a commit without a body has none.
Accessibility
Plain text.
Not for
Text written in Slath (rendered Markdown).

{%- endcall %} {%- endcall %} {%- call cat::entry("diff", "Diff", "Stable") %}
Purpose
Every diff, rendered by the same code: each file in its frame, folded files with their reason, changed characters marked (not by color alone), line numbers fixed while long lines scroll, links (or n and p while the diff has focus) to the previous and next change, and links that show the unchanged lines hidden above, between, and below the changes (in place, or the file alone without JavaScript). On merge requests, each file and each change has a viewed toggle. Side by side only where there's room.
Markup
repo/diff_files.html with the page's diff view.
Variants
Unified; side by side (wide screens); folded; binary; renamed; with threads; with hidden lines shown; a text such as a change's description compared across versions (pre.commit-body.description-diff, a span per line, diff-del and diff-add with a hidden marker and "Removed:" or "Added:").
Accessibility
A real table with line numbers as row headers, added and removed lines announced as words, and a "skip to the next file" link per file.
Not for
Code without a change (a code view).

{%- endcall %} {%- endcall %} {%- call cat::entry("markdown", "Rendered Markdown", "Stable") %}
Purpose
Text written by people (descriptions, comments, READMEs) at the long-form size and line height; references keep their state quietly (a closed issue is secondary text).
Markup
div.markdown around the sanitized HTML. Its headings start below the level of the section that shows it.
Variants
None.
Accessibility
Semantic HTML from the Markdown; images keep their alt text.
Not for
Text Slath writes.

{%- endcall %} {%- endcall %} {%- call cat::entry("editor", "Markdown editor", "Stable") %}
Purpose
One field with two modes (rich text and Markdown source) that the person switches between and that is remembered, a Write/Preview switch, a toolbar, and suggestions for people, issues, labels, and milestones.
Markup
slath-editor around the field's textarea, in a wide form.
Variants
Rich text; source; preview; with a draft restored.
Accessibility
Never traps the keyboard (Tab leaves it); every tool has a name, a shortcut, and a help dialog. Without scripts it's the plain text field.
Not for
Short single-line text.
