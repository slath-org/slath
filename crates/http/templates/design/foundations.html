Foundations

Typography sets the hierarchy, Source Sans 3 for the interface and JetBrains Mono for code. Colors, sizes, and spacing come only from tokens; buttons and icons are the smallest parts every page shares.

{%- call cat::entry("type", "Typography", "Stable") %}
Purpose
One size per role: page title 26 px, section heading 20 px, subsection heading 18 px, interface text 15 px, dense lists and tables 14 px, secondary facts 13 px, long-form text 16 px. Small text is never below weight 400; muted text uses the secondary color, never opacity.
Markup
Headings and text elements take their size from their level and component; no font sizes in pages.
Variants
The four heading variants (details heading, card headline, file heading, message heading) keep their level and change only the size.
Accessibility
Sizes in rem, so the person's font settings scale everything; text stays readable at 200 % zoom.
Not for
Code (the monospace face).

Purpose
Code and technical identifiers in JetBrains Mono, without programming ligatures, at the person's code size (12–20 px): code views, inline code, branch names, paths, hashes, commands.
Markup
pre.code-view as a scrolling region; code inline.
Variants
Block; inline.
Accessibility
A code block is a focusable region with a name, so it scrolls by keyboard; code stays left to right in every language.
Not for
Names written by people.

Purpose
Actions. The primary action uses the accent color, at most one per form and one per page heading; others are plain or quiet; destructive ones are red and name what goes.
Markup
button.button with button-primary, button-quiet, or button-danger; button-icon for icon-only ones (named, with a tooltip).
Variants
Default, primary, quiet, danger, icon-only. States: hover, focus, active, disabled, busy (spinner).
Accessibility
At least 24 px targets, 44 px under touch; visible focus; names that say what happens.
Not for
Going somewhere (a link).

Purpose
Lucide icons from the page's own sprite, at 1.25 em, always next to words or with a name: never the only carrier of meaning.
Markup

Variants
The icons below.
Accessibility
Decorative (aria-hidden); the element around them has a name.
