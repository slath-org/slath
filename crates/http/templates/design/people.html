People

Wherever Slath writes an account's name, its avatar comes right before it, for every name in a line. Text written by people (Markdown, mentions) shows names as written, and Git identities, which anyone can write into a commit, get a neutral person icon.

{%- call cat::entry("account", "Account name", "New") %}
Purpose
A person's, organization's, or bot's name in status lines, timeline events, headers, list facts, details columns, check reporters, menus, and tables: the avatar, then the name, then the Bot badge for a bot.
Markup
p::account(ctx, name, link): one link to the account, or plain text where the line is already a link.
Variants
Linked; not linked; a bot (with its badge); uploaded or generated avatar. An account that no longer exists is p::deleted(ctx, text).
Accessibility
The avatar is decorative; the name is text inside the same link, so there's one target and one tab stop.
Not for
Names in Markdown; Git authors and committers (Git identity); the global bar's own avatar and profile pages (larger avatars).
{%- call cat::example("Timeline events with several names, a bot, and a deleted account.") %}
  • {% call p::account(ctx, "alice") %}{% endcall %} requested a review from {% call p::account(ctx, "bob") %}{% endcall %} and {% call p::account(ctx, "acme") %}{% endcall %}
  • {% call p::account(ctx, "e2e-lint") %}{% endcall %} reported lint: failure
  • {% call p::deleted(ctx, "A deleted user") %}{% endcall %} opened this
{%- endcall %} {%- call cat::example("In a list row's facts, where the title is the row's link.") %}

#14 opened 3 hours ago by {% call p::account(ctx, "alice", false) %}{% endcall %}

{%- endcall %} {%- endcall %} {%- call cat::entry("git-identity", "Git identity", "New") %}
Purpose
The author or committer written into a commit. When the commit's email address is a confirmed address of an account (any of its addresses, or its no-reply address), it's that account: the account name with its avatar, and the name as written in the commit in the tooltip, so one person's commits under several addresses all show as their one account. An address no account has confirmed is shown as written, with a neutral person icon. Who pushed, merged, or applied a suggestion is an account Slath authenticated, said in words.
Markup
p::git_identity(ctx, name, account): account is the matched account's name, or empty.
Variants
Matched (an account name); unmatched (the person icon and the name as written).
Accessibility
The avatar and the icon are decorative; a matched name links to the account.
Not for
Accounts Slath knows from a session or token (the account name); matching by name or by an unconfirmed address.
{%- call cat::example("A commit by an account's address, committed under an address no account has confirmed, pushed by an account.") %}

{% call p::git_identity(ctx, "Alice Example", "alice") %}{% endcall %} authored, {% call p::git_identity(ctx, "Build Server", "") %}{% endcall %} committed a1e62f5c7d, pushed by {% call p::account(ctx, "alice") %}{% endcall %}

{%- endcall %} {%- endcall %} {%- call cat::entry("avatar-group", "Avatar group", "New") %}
Purpose
Several accounts in a small space, such as the reviewers in a list row: up to three avatars side by side, then "+N".
Markup
p::avatar_group(ctx, names).
Variants
One to three; more than three.
Accessibility
All names are text for screen readers; the avatars and "+N" are hidden from them.
Not for
Lists where the names matter (account names).
